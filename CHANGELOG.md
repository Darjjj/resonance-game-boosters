# Changelog

## 1.1.2 (unreleased)

- Reduce Auto+ result confirms from 500ms to 100ms. Normal result handling and input guards remain in place.

## 1.1.1 (unreleased)

- Use the shipped Blueprint result screen's normal confirm handler; its native base page fields are unused.

## 1.1.0 (unreleased)

- F4 cycles Off, Auto-Battle, Auto-Battle and Complete.
- Complete mode advances ready battle-result pages and uses an Auto+ badge.
- Existing Auto-Battle settings are preserved. Local build awaits in-game verification.

## 1.0.1

- Fixed booster icons staying hidden after battles: a retained battle-sequencer widget is no longer treated as a pause menu.
- Actual pause menus, battle results and cutscenes still hide the icons.
- Added the F1–F5 demo.
- Recommend setting the game's own battle speed to 1x when using Turbo Mode.


## 1.0.0

Initial public release under the MIT License.

- Turbo Mode (1x/2x/4x), Supercharge, Encounter Rate, Auto-Battle and full HUD toggle.
- Native in-game badges support exclusive fullscreen and fixed inactive slots.
- Icons hide on title/pause menus, battle results and detected cutscenes.
- Consistent x2/x4 artwork and reduced battle overhead.
- Files use resonance_boosters; legacy settings can be migrated.
